### 1. The `/bin/` Problem (Permissions)

*   **On macOS:** This will almost always fail because `/bin` is owned by the OS and is read-only for standard users.
*   **The "Nix Way":** Nix is designed to avoid touching `/bin` or `/usr/bin`. Instead, it puts everything in the `/nix/store`. 

`writeShellScript` creates a file in the `/nix/store` and makes it executable automatically. It doesn't need a `destination` attribute because Nix manages the location for you.

### 2. The PATH Problem (Dependencies)

*   **`writeTextFile`**: This creates a raw text file. If you write `qemu-img` inside that file, the script will look for `qemu-img` in your **system's** PATH (e.g., `/usr/local/bin`). Since you haven't installed QEMU globally, the script will fail with `command not found`.
*   **`writeShellScript`**: This creates a "wrapper." Nix looks at the inputs used to build that script and automatically sets up the environment so that `qemu` and `qemu-utils` are available to that script only.

The reason `test.log` is empty is a classic **buffering issue**.

When you use `timeout`, it sends a "Kill" signal to QEMU. Because QEMU is emulating a hardware serial port, it often buffers the text in memory before writing it to the disk. If QEMU is killed abruptly by `timeout`, that buffer is wiped out before it ever hits the file. When you kill it manually, you give the OS a split second to finish the "write" operation.

The best way to fix this for research is to let QEMU output to the **standard output** (the terminal) and use the `tee` command to write that output to a file simultaneously. 

This solves three problems at once:
1.  **No more empty logs**: `tee` writes to the file as soon as the characters appear.
2.  **Real-time feedback**: You can see the boot process happening in your terminal instead of waiting 30 seconds to see a log.
3.  **Safety**: It doesn't matter how QEMU is killed; `tee` has already saved everything that was printed.

To handle cleanup automatically, we can use a shell `trap`. This ensures that even if the script finishes successfully, crashes, or is interrupted by you (e.g., pressing `Ctrl+C`), the generated files are deleted.

Here is the updated `flake.nix`:

```nix
{
  inputs.nixpkgs.url = "github:nixos/nixpkgs/nixos-unstable";

  outputs = { self, nixpkgs }: 
    let 
      system = "aarch64-darwin";
      pkgs = import nixpkgs { inherit system; }; 
    in {
      packages = {
        ${system}.default = pkgs.writeTextFile {
          name = "qemu-research";
          executable = true;
          destination = "/bin/qemu-research";
          text = ''
            #!${pkgs.stdenv.shell}
            
            BASE_DIR=$(pwd)
            DISK_PATH="$BASE_DIR/test_disk.qcow2"
            LOG_PATH="$BASE_DIR/test.log"
            ERR_LOG="$BASE_DIR/qemu_error.log"

            # --- Cleanup Function ---
            cleanup() {
              echo "-----------------------------------------------------------"
              echo "Cleaning up generated files..."
              rm -f "$DISK_PATH" "$LOG_PATH" "$ERR_LOG"
              echo "Done."
            }

            # Trap signals: Run cleanup on exit, interruption (Ctrl+C), or termination
            trap cleanup EXIT INT TERM

            # 1. Ensure disk exists
            if [ ! -f "$DISK_PATH" ]; then
              echo "Creating disk image..."
              ${pkgs.qemu-utils}/bin/qemu-img create -f qcow2 "$DISK_PATH" 512M
            fi

            # Clear the old log
            > "$LOG_PATH"

            echo "Starting QEMU in background (15s timeout)..."
            
            # 2. Start QEMU in the background
            ${pkgs.qemu}/bin/qemu-system-x86_64 \
              -hda "$DISK_PATH" \
              -nographic \
              -display none \
              -serial file:"$LOG_PATH" \
              2> "$ERR_LOG" &
            
            QEMU_PID=$!

            # 3. Wait 15 seconds
            sleep 15

            # 4. Kill the process
            echo "Killing QEMU (PID: $QEMU_PID)..."
            kill $QEMU_PID 2>/dev/null || true

            # Small pause to let the OS flush the file handle
            sleep 0.5

            echo "-----------------------------------------------------------"
            echo "Serial Log Content:"
            if [ -s "$LOG_PATH" ]; then
              cat "$LOG_PATH"
            else
              echo "Warning: $LOG_PATH is still empty."
              if [ -f "$ERR_LOG" ]; then
                echo "Startup Errors:"
                cat "$ERR_LOG"
              fi
            fi
            echo "-----------------------------------------------------------"

            # The trap handles the final cleanup
            true
          '';
        };
      };
    };
}
```

3.  **Streamlined Logic**: The script remains exactly the same otherwise, but it's now "self-cleaning."
